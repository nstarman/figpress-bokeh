# figpress-bokeh

A paper's figures in Bokeh: one definition gives the print figure the paper publishes (PDF) and a
matching interactive web figure. Part of the [figpress](https://nstarkman.space/figpress/) family.

Not written yet; the first release is specified in [`specs/001-first-release`](specs/001-first-release/spec.md).
